## What changed

**Layout.** `git mv prototype app`; `package.json` name `app`; folder paths updated in `context/PLAN.md`, `PROTOTYPE-PLAN.md`, `PRODUCTION-PLAN.md`, `app/docs/slices/F00.md`. New root folders: `supabase/` (`config.toml`, `migrations/`, `seed.sql`, `tests/`), `.github/workflows/ci.yml`, `production/docs/`.

**Hygiene.** `playwright-report/`, `test-results/` untracked (`git rm --cached`, 132 files) and git-ignored; `tsbuildinfo` was already ignored. ESLint ignores both folders.

**Environment contract.** `src/env.ts` (zod) is loaded from `next.config.ts`, so `build`, `dev` and `start` fail on a bad env. Rules: `mock` refused in staging/production; Supabase vars required when `DATA_SOURCE=supabase` in staging/production; `NEXT_PUBLIC_TODAY` only when `APP_ENV=test`; `NEXT_PUBLIC_LATENCY` not when hosted; any `NEXT_PUBLIC_*SERVICE*/SECRET*` variable refused. `.env.example` documents them. `APP_ENV` defaults to `production` for builds without it. 8 unit tests in `tests/unit/env.test.ts`.

**Dev surface compiled out.**
- `/dev/*` pages renamed `page.dev.tsx`; `next.config.ts` adds the `dev.tsx` page extension only for `APP_ENV=development|test`. In staging/production they are not routes at all.
- `?latency=`, `?fail=`, `NEXT_PUBLIC_LATENCY` (`repo.ts`) and `?fixture=` (`store.ts`) sit behind a per-module `process.env.NEXT_PUBLIC_DEV_TOOLS === "1"` constant that Next inlines. (An imported flag was not folded across modules; that was tried first and failed the check.)
- `lib/data/fixtures.ts` is replaced by `fixtures.stub.ts` through `turbopack.resolveAlias` in hosted builds, which removes the 58 Figma fixtures from the client bundle.
- `lib/clock.ts` honours `NEXT_PUBLIC_TODAY` only when `NEXT_PUBLIC_APP_ENV=test`. Vitest and Playwright set it (`APP_ENV=test`, `DATA_SOURCE=mock`).

**Build check.** `npm run check:build` (`scripts/check-build.mjs`) after `next build`: no `/dev` route in the app-paths manifest; no fixture names, hook strings, test-only env names or service-role references in client JS. Negative control: a `APP_ENV=test` build fails it with 11 dev routes listed.

**CI.** `.github/workflows/ci.yml`: job `app` (typegen, `tsc`, eslint, G1, vitest, `next build` with `APP_ENV=production` and placeholder non-secret Supabase values, `check:build`); job `database` (`supabase start`, `supabase test db`, one placeholder pgTAP test).

**G1 cleanup (was ⚠ in F15).** `motion.css` px literals replaced by `var(--spacing-4)` and comment rewording; `PaymentInstruction` comment reworded; login shader inputs (two hex colours, grain size and opacity) moved to `components/login/liquidParams.ts`. **Policy change for you to confirm:** that file is now on the G1 allow-list (`scripts/check-g1.mjs`) because WebGL inputs are not UI tokens. Rendering is unchanged (the opacity class became an inline style with the same value).
