## Contract (for P3's mapper)

- **Errors:** SQLSTATE `P0001`, `message` = the prototype's code, unchanged.
  - `save_booking` raises `booking_invalid` with `details` = the `BookingErrors` JSON (including `items` keyed by row and `minimumTotal`), or `not_found`.
  - `create_invoice` raises an `InvoiceError` code, or `not_found`.
  - `cancel_booking` raises `not_found`, `not_allowed` or `reason_too_long`.
  - Every write raises `forbidden` for a non-admin.
- **Returns:** `save_booking` and `cancel_booking` return the `bookings` row. The two invoice RPCs return `{invoice, booking}` JSON.
- **Snapshots** have exactly the prototype `InvoiceSnapshot` keys. `snapshot_hash` is sha256 of `canonical_json()`, which reproduces the TypeScript `stableStringify()`. Proven on all 41 seeded invoices.

## Decisions

1. **SECURITY DEFINER** on the four RPCs and `is_admin()`. RLS is on with no write policies, so these are the only write path. Each pins `search_path = ''` and calls `require_admin()` first. Internal helpers are revoked from `public`, `anon` and `authenticated`. Only the four RPCs and `is_admin()` are granted to `authenticated`.
2. **Item replace order:** new items are inserted, then the booking row is updated, then the old items are deleted. `check (total_paid <= total)` is checked per statement, and delete-first broke a valid "edit down to exactly paid" (caught by the vectors).
3. **Stricter than the prototype, on input the UI never sends:**
   - An unknown or malformed booking id raises `not_found`; the prototype would create a new booking.
   - An impossible date (`2026-02-30`) gives `bookingDate: invalid`; the prototype only checks the year.
4. **Actor:** `created_by` / `canceled_by` = `auth.uid()`. The snapshot `createdBy` is the caller's `display_name`, or "System" when there is no profile.
5. **Numbering year:** Asia/Jakarta. A number already taken above the counter is skipped, as the prototype's `nextNumber` does.
6. **Known length nuance:** SQL `char_length` counts code points, JS `.length` counts UTF-16 units. They differ only for emoji and other astral characters in names and terms. Left as is; noted for P10.
