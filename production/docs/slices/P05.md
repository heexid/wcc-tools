## Bug found and fixed

When the connection drops, a Server Action call **throws** in the browser instead of returning `{network:true}`. The Supabase repo only handled the returned form, so a dropped connection would have been an unhandled error instead of the prototype's error screens (Package 06, Bookings 23 / 37, Login E6). `settled()` now converts both into `NetworkError`. The logout call never throws, so local sign-out always completes.
