## Findings (affect every later slice)
1. **Figma uses Inter 3.x** (variable axes `slnt` + `wght`). Google Fonts' Inter 4 (`opsz`) was off by up to 1.3 px at 10–13 px. Inter 3.19 fixes it.
2. **Figma rounds auto-width text boxes up to whole pixels** and excludes the trailing letter-spacing. Browsers keep fractional widths, so hug-content rows (chips, buttons, tabs) can drift by < 1 px per text node. G3's 0.5 % allowance covers this; if a row accumulates visible drift, give that text a token width rather than a raw value.
3. Next.js dev badge / issue toast sits inside the 1440 frame → `devIndicators: false`, and G3 fails if an issue toast is present.
4. `cacheComponents` is on: any page that reads `searchParams` must do it in a Suspense boundary (client `useSearchParams` or a suspended server child).
5. `pnpm` is not installed → npm. Playwright 1.65 / Chromium installed.
