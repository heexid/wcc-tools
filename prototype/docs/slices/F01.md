## Motion (§1 steps 5–6)
- `find-animation-opportunities` accepted 3: **Toast** enter/exit bottom edge, **ModalPanel** scale-in (centred, faster exit), **ShellPopover** grow from trigger. Rejected: tab underline slide (core navigation, tens/day), checkbox pop (frequent), error helper fade (must be instant), pagination/metric count-up (data being read), search clear fade (constant typing).
- `animate` built them as opt-in CSS (`motion.css` `.motion-toast|-modal|-popover` + `@starting-style`, transitions not keyframes, transform + opacity only) driven by `usePresence(open)` → `data-state`. Reduced motion = fade only (movement vars neutralised). Already present from F0/F1 build: hover colour (`--dur-hover`), press scale (`--press-scale`), segmented slide (`--dur-indicator`, `--ease-in-out`), loading spin.
- Feel-check later on real flows: toast 400 ms travel (F10/F11), popover origin per trigger (F4).

## Findings (Figma ↔ browser, apply to every later slice)
1. **Text boxes:** Figma's auto-width text = `ceil(glyph width − trailing letter-spacing)`, glyphs at the box's left edge. Use `<Txt>` for single-line labels in hug/centred layouts. Without it every button/badge/tab is up to 1px narrower and centred labels sit on half pixels.
2. **`<button>` centres text** (UA `text-align: center`) — `Txt` forces `text-left` so glyphs land where Figma puts them.
3. **INSIDE strokes count in layout** (`strokesIncludedInLayout`) → CSS border-box + 1px border. Focus variants drop the stroke (hug width −2, fixed height kept) → ring drawn as `::after`.
4. **Inner shadows paint over strokes** (and over an outside focus ring) → Button highlight is a `::before` above the border, not a CSS `inset` shadow.
5. **Fractional render bounds** (e.g. focus-ring spread 3 + blur 0.5 → −3.5) make Figma rasterise the whole node at a half pixel → export those at node bounds, mask the effect band, verify the effect through computed style.
6. **Figma sample content is sometimes inconsistent** (T&C 174 chars vs "267/255"; password "Value" with the hidden icon) → masked with a written reason in `F01-variants.json`.
7. **G3 on components:** Figma and Chrome antialias glyphs/curves differently (~10–20 % of edge pixels). Flat 0.5 % budgets fail on rasteriser noise for small text-dense components, so components use **G3c**: 0 flat-area diffs, ≤ 20 % edge diffs (screens keep G3 ≤ 0.5 %).
8. Tailwind 4: any `before:` utility gives `::before` content → only add `before:` classes where the pseudo-element is positioned; `outline-none` sets `--tw-outline-style: none` (use the ring pseudo instead).
