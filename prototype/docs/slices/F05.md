## Masks (Figma quirks, with reason)
- **Pagination** — Figma's list footer shows pages 1–5 although all packages fit on one page; we show the real page count (01–06, L3).
- **05 field values** — Figma draws the invalid name in placeholder grey (Input Error variant default, as Login E2) and the empty price as "Rp"; we keep typed text primary and show the "Rp 0" placeholder.

## Findings
- **Half-pixel rows:** Figma centres a 42 px cell in a 61 px row (62 − 1 px bottom stroke) → text at y + 9.5; Chrome snaps text to whole pixels (sub-pixel sweep: no offset helps). This is the bulk of the list frames' 0.24–0.39 % — renderer-level, inside the gate.
- Playwright `getByRole({ name })` is a substring match — use `exact: true` when one accessible name contains another.
- Focus after a destructive stacked-dialog action must be placed by the page (the opener's row disappears only after the reload).
