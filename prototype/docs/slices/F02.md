## Data decisions (Figma ↔ data)
- **Canonical = screen 01 (month) + 02 (table).** Every named booking, client, phone, package, item, crew and invoice keeps Figma's exact values.
- **Invented data fills the gaps** and is tuned so the data produces Figma's numbers: 14 Partially paid with **Rp 48.750.000** outstanding, **Rp 61.200.000** collected in Nov, **+12,4 %** vs Oct (Rp 54.450.000), Raka "5 bookings in Nov", Package Library counts (18 / 11 / 23 / 9 / 6 / 4, archived 31 / 12 via `legacyBookings`).
- **Scenario screens** (new-booking flow 03–05c, edit flow 09–10, busy week 31, canceled 35, archived 38/39, empty 36/40, Package 07) are fixtures that patch the seed.
