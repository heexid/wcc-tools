## Findings
- **Focus race:** focusing the first tile/menu item in a `requestAnimationFrame` must be cancelled on close — otherwise a fast Esc puts focus back in the closed popover. Found by the full-suite run under load; fixed in both popovers.
- G3 helper now supports **region clips** (`clip`) and **`keepPointer`** (for designed hover states, L2); `settle()` moves the mouse away by default.
- Importing a helper from a spec file registers that spec's tests too → shared helpers live in `tests/helpers/` (`session.ts` → `signIn`).
- Lane B (Package Library → Booking, M1–M3) has no separate frames in Figma; it is covered by the behaviour tests and L3's header.

## Motion
- Popovers reuse F1's `.motion-popover` via `usePresence` (origin top-left for the launcher, top-right for the menu).
- `find-animation-opportunities`: 1 accepted — press feedback on the custom pressables (tiles, ⋮⋮, profile pill). Rejected: header/module swap on navigation, route content entrance, locked-tile shake, tile stagger, menu item slide.
- `animate`: `active:scale(var(--press-scale))`, `--dur-press` `--ease-out`, transform added beside the colour transitions; locked tile excluded; reduced motion → scale 1. Feel-check the 124 px tile press on real hardware.
