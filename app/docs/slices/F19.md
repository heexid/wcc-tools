# F19 — Booking event details (event start · location · notes)

**Status:** ✅ Done · 2026-11-21 — prototype (mock) and production (Supabase), one change.

## What changed (Figma first, then code)
- **Booking form** (Figma Bookings: all 41 form frames): the first section is **Client & schedule**. Schedule was merged into it: booking date · **Event start** · Created in one row, then **Location** and **Notes** text areas (≤ 255 each). The **Payment instruction** card moved from *Package* to the top of *Others*. Every form frame grew 251 px; sections, overlays, modals, flow hotspots and arrows were reflowed.
- **Invoice PDF** (Figma 11 / 11b / 11c / A5 / A5b / Profile E4): simplified header. Meta = Invoice date + Booking ref (booking date no longer repeated). Parties = **Bill to** (name, phone) | **Event** (booking name, 1 line; date · start; location, ≤ 2 lines; "Notes: …", ≤ 2 lines, secondary). The redundant *From* column is gone (it repeated the Brand row). Header pad `space/section`, header + body gap `space/16`: the longest location + notes still fits one A4 page (5 px spare).
- **Date picker** now opens below the Booking date field (it moved to the top of the form).
- **Detail sheet** (Figma: all 15 drawers): *Booking information* follows the form's order: Client · Phone · Booking date (· start) · **Location** · **Notes** · Package · Crew · Payment · Created. Location / notes wrap in full; empty event rows are hidden (Graduation · Aulia drawers show none). New DS icons **Icon/map-pin** and **Icon/file-text** (Lucide, 20 px, 1.5 stroke) added to CIR Icons and `icon-paths.ts`. Crew popovers (S2, 27) and flow hotspots shifted with the rows.

## Decisions
- All three fields are optional. Old invoices keep their snapshot (rule 4): no event keys → the PDF shows booking name + date only.
- Notes are **printed on invoices** (the user asked for them on the invoice), so the form helper says so; Figma helper copy was updated to match.
