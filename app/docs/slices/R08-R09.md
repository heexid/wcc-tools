## R09 · Mobile type scale and sizing (2026-11-23)

| Style | Desktop | Mobile (< 768) |
|---|---|---|
| Heading/Module (top bar, sheet titles) | 15/20 | 17/24 |
| Heading/Section | 16/24 | 17/24 |

Page / Panel headings, Display, Label, Metric Label and Avatar keep their sizes. Smallest text on a phone: 12 px.

**Code.** `tokens/figma.styles.json` gained `mobileText`; `scripts/build-tokens.mjs` writes each one as a
`--text-<name>` / `--text-<name>--line-height` override inside `@media (width < 48rem)`, so every component follows
without per-component classes. Controls and fields stay 44 high (R01).

**Sizing.**
- Mobile cards (booking list item, agenda item, line-item card, package card) pad 16 (`space/base`), in Figma and code.
- Status badges are a fixed 24 high at every size (they hugged the larger label in Figma).
- Package card rows: name + price / description / usage + status (usage no longer wraps beside the price).
- Invoice card: the issue date wraps under the number instead of running into the amount.
- "Remaining after save": amount on its own line, right-aligned, when it doesn't fit beside the label.
- Field helpers and labels wrap on mobile; the Invoices empty title and "No logo…" caption wrap.
- Agenda month nav wraps at 320 (Today moves under the month instead of off-screen).
- Edit booking: Cancel booking is the last section on mobile (after Updated totals and Invoices), in DOM order too.

**Figma.** All 1,691 text nodes in the four mobile sections and the mobile DS components use the `Mobile/…` styles;
badge instances pinned to 24; sheets re-anchored; reference PNGs (`public/__figma__/mobile-*.png`) re-exported.

**Tests.** Mobile e2e 90/90 (gates against the re-exported frames pass); `tests/unit/tokens.test.ts` checks the mobile
overrides; overflow suite green at 320–390.

**Known.** Figma's CIR Input field still draws 36 / 13 (no mobile size in the DS); code renders 44 / 16. Icons keep
their desktop sizes.
