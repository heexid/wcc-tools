## New DS pieces (CIR · Design System)
- `Mobile/Booking list item` (State Default / Selected) in *Booking components*: props Ref, Booking, Amount, Date · client, Remaining label; nested Payment status badge.
- `Mobile/Agenda item` (Status Draft / Partially paid / Paid): Calendar/Day row at 358; props Title, Meta, Amount, Remaining.
- `Mobile/Line item card`: replaces Line item row; exposed Item / Price / Qty inline inputs (44), Subtotal prop, 44 remove target.
- `Icon/sliders-horizontal` (Lucide, 20 / 1.5) in Icons — Filters chip.

## Decisions / gaps
- Input field has no mobile size in CIR (single-mode collections on this plan → no Desktop/Mobile modes). Figma frames show 36 / 13px like the DS's own Mobile/Editor; **code uses 44 / 16px** from R01 tokens. Buttons, search and inline inputs are bound to `mobile/*` in the frames.
- KPI cards are on mobile since 2026-11-24 (M01–M03: 256-wide cards, scroll-x, between title and tabs); Calendar | List tabs stick under the top bar (M03b).
- Not on mobile: Upcoming rail, Needs attention (Mobile/Insights pattern could bring them back later).
- No copy-link in share (signed URLs expire); WhatsApp API sending stays v1.1 — the OS share sheet covers WhatsApp.
- Tablet: desktop layouts + tablet tokens; no frames.
- Not yet designed: edit booking (M05 with saved state + Cancel booking), canceled read-only, crew schedule popover, login/launcher/account (DS Mobile/Login, Mobile/App launcher, Mobile/Account exist), Package Library.
