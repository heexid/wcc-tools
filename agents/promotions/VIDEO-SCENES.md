# Promo video: scene by scene

**Length:** about 40 seconds · **Format:** 16:9 screen recording with motion graphics · **Focus:** the four main features only

---

**Scene 1 · 0–5s · Hook: the chaos**
*Visual:* Fast cuts of a chat thread buzzing with messages, a spreadsheet with a red "#REF!" error, a receipt slipping off a desk. Quick, messy, a little funny.
*Sound:* Notification pings, then everything stops at once.
*VO:* "Deposits in one chat. Totals in a spreadsheet. Invoices nobody can find."

**Scene 2 · 5–8s · The turn**
*Visual:* The chaos swipes away like a closing tab. A single clean dashboard fades in with a soft chime.
*VO:* "Let's make that a lot less messy."

**Scene 3 · 8–18s · Feature 1: Book it in one form**
*Visual:* A booking form types itself in: client name, package picked from a dropdown, extra items added one by one. The total on the summary card counts up with each number, like a cash register ticking.
*Motion:* Each field glows briefly as it fills.
*VO:* "One form. Client, package, extras, date. The total does the maths for you, live."

**Scene 4 · 18–26s · Feature 2: Take the payment**
*Visual:* A "Create invoice" button is tapped. The DP toggle slides to 50%. A stamp animation lands: PAID. The status badge morphs from Draft to Partially paid.
*Motion:* Stamp bounce, then the badge colour shifts smoothly.
*VO:* "Take a deposit or the full amount. It's recorded the moment it's paid, and it never changes after."

**Scene 5 · 26–33s · Feature 3: Know what's due**
*Visual:* The calendar fills with coloured booking chips. The camera zooms into today, where a "Balance due today" card pulses gently. A search for a client's name filters the table in real time.
*Motion:* The chips drop into place one by one, like tiles settling.
*VO:* "See every booking, and spot the balances before they become a problem."

**Scene 6 · 33–39s · Feature 4: Invoices in one click**
*Visual:* A PDF slides out of the screen and unfolds into an A4 page. The logo animates in at the top, followed by the total. The file name "INV-2026-0001" types out.
*VO:* "Send a clean, branded invoice in one click. Update your details once, and every invoice carries them."

**Scene 7 · 39–42s · Close**
*Visual:* All four features collapse into one logo. A button appears: "Start your first booking."
*VO:* "One place for every booking and every payment. Start today."
*End card:* Logo · "Start your first booking"

---

## Notes for the editor

- Keep the four features in this order: they follow the booking journey (create → get paid → track → invoice).
- Show only desktop screens. The app is not built for mobile, so don't frame it in a phone.
- Use real-looking sample data (for example, a client name and a package from the seed data) so the numbers look believable.
- Confirm the fine details before filming: the DP percentage shown, the invoice number format, and the status labels.
